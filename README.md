# Ателье карточек

Личный инструмент для Instagram магазина декора: план публикаций, промты для картинок (генерируются в ChatGPT), тексты постов, Reels и сторис, проверка картинок, статистика и рост.
Работает как обычная страница и ставится на телефон как приложение. Ключи и данные хранятся в браузере и в личном проекте Supabase — в репозитории их нет.

## Как устроено
- **Лента** — план сеткой, как профиль Instagram, и полоса «Сегодня».
- **＋** — один пост или план на неделю/N постов: типы по ритму, рубрики по долям, цели, товары, поводы, идеи ИИ.
- **Пост** — одна кнопка «Создать промт и текст», дальше подсказка следующего шага: промт → ChatGPT → загрузить картинку (ИИ проверит) → опубликован → статистика. Любой блок дорабатывается кнопками-пожеланиями с отменой.
- **Идеи** — банк идей, календарь поводов, разбор конкурентов по скриншоту.
- **Рост** — статистика и выводы, проверка плана и сетки, аудит профиля, пробные Reels, коллабы.
- **Профиль** — бренд, товары, подключение (ключ Claude, Supabase), списки сцен, резервная копия.

## Файлы
- `index.html` — оболочка и нижнее меню.
- `app.css` — стили (сначала телефон).
- `app.js` — экраны и логика.
- `prompts.js` — все шаблоны промтов и ИИ-запросов (чистые функции — удобно дорабатывать отдельно).
- `core.js` — хранилище (Supabase `kv` / localStorage) и вызовы Claude.
- `sw.js` — офлайн-кеш оболочки (при изменении файлов поднимайте `CACHE` и `?v=` в `index.html`).

## Проверка
Запустите локальный сервер в папке (`python -m http.server 8765`) и откройте:
- `test/prompts.test.html` — шаблоны промтов, ритм, рубрики, поводы, метрики;
- `test/flow.test.html` — сквозной сценарий без ИИ и отсутствие горизонтальной прокрутки на 390px;
- `test/ai-flow.test.html` — цепочка ИИ на фиктивных ответах;
- `test/frame.html?r=feed` — приложение в рамке телефона 390×844.

Тесты `flow` и `ai-flow` очищают данные приложения в этом браузере — запускайте их в отдельном профиле.

Данные прошлой версии подхватываются автоматически: старые карточки получают постоянные номера по возрасту.
